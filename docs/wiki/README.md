# Publishing the wiki index

The public Polaris-docs repository has Wiki enabled with editing restricted to collaborators. Publish `Home.md` and `_Sidebar.md` through its wiki editor; preserve any custom pages. This directory contains the version-controlled sources, and changes here do not automatically update the separate GitHub wiki.

The wiki links to the maintained handbook instead of duplicating its instructions. GitHub Pages uses the Actions workflow in this repository and requires no `PAGES_ENABLED` variable. Verify the successful deployment and live site after merging documentation updates.

The application remains private. Never copy environment files, private review notes, chat logs, credentials or production exports into either publication surface.
